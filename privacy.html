Privacy Policy

Personal Assistant · Last updated 7 September 2026

Personal Assistant is a private application with a single user: its owner. It is not offered as a service to anyone else and does not accept sign-ups. This policy describes what it accesses, where that data goes, and how long it is kept.

Information accessed

With the owner's explicit Google authorization, the application accesses:

DataAccessPurpose
Google Calendar events Read Answering questions about the schedule; building the daily summary
Google Tasks Read, and write when explicitly requested Showing what is due; creating and completing tasks on request

No other Google data is accessed. The application does not request access to Gmail, Contacts, Drive, Photos, or location history.

It also stores the conversations the owner has with it, and a log of every action it takes.

Where data is stored

All stored data lives in the owner's own private Amazon Web Services account, in the US East (Ohio) region. It is encrypted at rest using a customer-managed encryption key controlled by the owner. There is no other copy, and no other person has access.

Third-party processing

Two services process data on the owner's behalf. Neither is given data for its own purposes.

  • Amazon Web Services — hosts the application and stores its data. Calendar events, task titles, and conversation content are sent to Amazon Bedrock, AWS's model-hosting service, to generate answers and the daily summary. Processing is restricted to AWS regions within the United States.
  • Open-Meteo — queried for weather forecasts. It receives an approximate location and no personal data.

Data is not sold, rented, shared for advertising, or used to train any model. The application contains no analytics, tracking, cookies, or advertising of any kind.

How long data is kept

  • Conversations — deleted automatically after 90 days.
  • Action log — a record of each action taken, kept for 5 years so past activity can be reviewed.
  • Daily summaries — kept until deleted by the owner.
  • Google data — read on demand and used to answer the request at hand. Calendar events are not copied into long-term storage; task and event details may appear inside stored conversations and the action log, and are removed with them.

Revoking access

The owner can revoke this application's access to their Google account at any time from Google Account permissions. Revoking access immediately stops all further reading of calendar and task data. Stored conversations and logs can be deleted directly from the owner's AWS account.

Security

Access requires signing in. Data is encrypted in transit and at rest. Any action that changes calendar or task data as a result of the assistant's own suggestion requires explicit confirmation before it runs, and every action is recorded in the action log.

Children

The application is not directed at children and has no users other than its adult owner.

Changes

Material changes will be reflected on this page with an updated date above.
